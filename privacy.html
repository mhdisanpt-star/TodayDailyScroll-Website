Privacy Policy

Last updated: October 19, 2026

Today Daily Scroll ("TDS", "we", "us") operates an Editorial Platform used by channel operators to plan, review, and publish video content. This policy describes data handling for TDS, including the TDS Podcast Google OAuth application used with the Today Daily Scroll Podcast YouTube channel.

This public website is static documentation. Operational data is processed on the secured TDS production host operated by authorized personnel — not in the visitor’s browser on these pages.

Who this applies to

TDS is primarily an operator / internal editorial tool, not a public consumer social login product. Google and YouTube OAuth are used by authorized operators to connect publishing channels they control. End viewers of published YouTube videos interact with YouTube under Google’s own policies.

Data we collect and store

Depending on which features are enabled, TDS may store:

  • Google / YouTube OAuth credentials — OAuth client identifiers and refresh tokens for authorized channels (for Podcast: dedicated Podcast credential keys, stored in the production server environment). Access tokens are obtained by refreshing those credentials when API calls are made.
  • Channel identifiers — YouTube channel IDs used to bind uploads and verification to the correct channel (Podcast does not fall back to other channel credentials).
  • YouTube API response data — video IDs, titles, upload status, privacy status, and related metadata needed to verify publishes; analytics metrics when Analytics access is used.
  • Editorial workflow data — job records, review decisions, production status, error messages, and operational logs in the TDS database and log files.
  • Source / media artifacts — downloaded or rendered media and caches used for production and review (stored on the server filesystem under the TDS runtime directories).
  • TikTok OAuth tokens — where TikTok publishing is configured, access credentials for the Content Posting / Login Kit flows.
  • Contact information — if you email us for support or privacy requests.

We do not sell personal data. We do not use OAuth data for advertising.

Google / YouTube OAuth scopes (TDS Podcast)

The TDS YouTube integration requests the following Google OAuth scopes so one consent can cover upload, channel reads, and creator analytics used by the pipeline:

  • https://www.googleapis.com/auth/youtube.upload
  • https://www.googleapis.com/auth/youtube.readonly
  • https://www.googleapis.com/auth/yt-analytics.readonly

Operators may revoke access at any time in Google Account permissions. Revocation prevents further API use until the operator re-authorizes.

How we use data

  • Run editorial discovery, production, review, and quality workflows
  • Upload and verify content on authorized platforms when publishing is enabled
  • Sync channel/performance analytics for operator dashboards
  • Maintain reliability, security, budgeting, and troubleshooting
  • Respond to support and privacy requests

YouTube API Services

TDS uses YouTube API Services and complies with the YouTube API Services Terms of Service. Use of information received from Google APIs also adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Google’s own privacy practices are described in the Google Privacy Policy.

TikTok API

Where TikTok Content Posting API is enabled, TDS uses tokens to upload and verify content the operator authorizes. TikTok data is used only for configured publishing features.

Storage location and sharing

  • OAuth refresh tokens and client secrets for YouTube live on the production server environment (for Podcast, dedicated Podcast environment keys). They are not published on this static website and are not intentionally exposed to public HTTP responses.
  • Operational databases and logs reside on the same production host (or backups controlled by the operator). Access is limited to authorized operators.
  • We share data with Google/YouTube (and TikTok when enabled) as needed to perform the API calls the operator authorized. We do not sell data to brokers.
  • Service providers that host infrastructure (for example VPS or DNS/CDN for this static site) may process technical connection metadata under their own terms.

Cookies

This public website is static and does not set advertising or analytics tracking cookies. The TDS dashboard, when self-hosted, may use session cookies or similar mechanisms for operator authentication.

Security

We use access controls and standard server-side practices to protect OAuth tokens, credentials, and operational data. Production access is limited to authorized operators. No method of transmission or storage is perfectly secure; operators should rotate credentials if compromise is suspected and revoke Google access promptly.

Retention

We retain OAuth credentials while a channel remains connected and the operator continues to use TDS for that channel. Editorial job records, media artifacts, caches, and logs are kept as long as needed for production, review, troubleshooting, budget accounting, and backups. Operators may request deletion of personal data they control, subject to legal and operational retention needs (for example audit or security logs).

Your rights

Authorized operators may request access, correction, or deletion of personal data we hold, and may revoke Google/YouTube/TikTok OAuth access through each platform. Viewers of public YouTube content should use YouTube/Google controls for their Google Account data.

Children

TDS is not directed at children. Operators must not use the platform to collect personal information from children in violation of applicable law.

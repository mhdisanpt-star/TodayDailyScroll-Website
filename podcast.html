Today Daily Scroll Podcast

TDS Podcast is the Google OAuth application used by Today Daily Scroll operators to authorize YouTube access for the Today Daily Scroll Podcast channel. It powers editorial production, human review, and (when explicitly enabled) publishing of short-form podcast clips.

YouTube Data API YouTube Analytics Operator tooling

What this app does

  • Authorizes the operator’s Google account for the Podcast YouTube channel
  • Supports upload, channel metadata, and analytics used by the editorial pipeline
  • Does not provide a public consumer sign-in or social login product
  • Keeps Podcast credentials separate from other TDS channels

Purpose

TDS is an Editorial Platform. The Podcast channel workflow discovers candidate sources, produces reviewable clips, and lets operators approve or reject outputs before any publish step.

Editorial production

Plan and produce Podcast shorts through a dedicated channel queue and review intake cap.

Human review

Operators review finished videos in the TDS dashboard before publication decisions.

YouTube publishing

Uploads use the authorized Podcast YouTube credentials only when the channel profile explicitly allows upload. Auto-upload can remain disabled while review continues.

Google / YouTube OAuth

Authorization is performed by channel operators using Google’s OAuth consent flow. Access tokens are refreshed server-side; refresh tokens are stored only on the secured production host (not on this public website).

  1. Consent — An operator authorizes the TDS Podcast Google Cloud OAuth client.
  2. Store — The refresh token is saved to the server environment for the Podcast channel.
  3. Use — TDS calls YouTube APIs to upload or read channel/analytics data as configured.
  4. Revoke — Operators can revoke access in Google Account settings at any time.

See the Privacy Policy for scopes, retention, and data handling details.
